# Bayo's Study Court

Listening-first study app: Grammar, Algebra 1, Biology, and World History, with level maps, read-aloud, and a parent progress page.

- `public/index.html`: the app (built from `source/`, run `python3 source/build.py`)
- `public/parent/`: parent progress page (PIN protected)
- `netlify/functions/progress.mts`: saves and serves progress (Netlify Blobs)
